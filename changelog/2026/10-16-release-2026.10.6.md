| Component | Summary (english)                                                                                | Relevance for consumers (English)                                                                                                                                                                                                                                                                                                                                                                                    | Relevance for end users (Dutch)                                                                                                                                    | Relevance for system administration (Dutch) |
| --------- | ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------- |
| ZRC       | Added: the `fields` parameter on the `_zoek` operation (API v1.7).                               | It is now possible to add a `fields` parameter to a `_zoek` request and so expand related resources and return only the fields you need, which reduces the size of the response. For example, `fields` can request only `identificatie` together with the `zaakinformatieobjecten`, their `informatieobject` and the `omschrijving` of the `informatieobjecttype`, to see which document types are valid for a zaak. |                                                                                                                                                                    |                                             |
| DRC       | Removed: version 1.0 of the DRC API standard is no longer supported.                             | Version 1.0 of the standard is no longer supported. The remaining supported versions are 1.1, 1.5 and 1.7, so consumers still using 1.0 have to switch to one of these.                                                                                                                                                                                                                                              |                                                                                                                                                                    |                                             |
| DRC       | Fixed: retrieving a document whose filename contains a question mark no longer returns an error. | Fixed: retrieving a document whose filename contains a question mark no longer returns an error.                                                                                                                                                                                                                                                                                                                     | Opgelost: documenten met een vraagteken in de bestandsnaam konden niet worden opgehaald en gaven een foutmelding. Deze documenten kunnen nu gewoon worden geopend. |                                             |
